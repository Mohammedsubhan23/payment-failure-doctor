How this works (model + AI layer)
Two real models, trained and evaluated, not rules. A RandomForest classifier assigns the root-cause bucket and a GradientBoosting model estimates retry-success probability, both trained on labelled transaction data with a held-out test set (92.9% test accuracy on bucket classification — see backend/train.py output for the full report). The LLM is only called after classification is done — it receives the model's output as ground truth and is instructed not to re-derive it, and is used strictly to turn numbers into a merchant-facing sentence, or to answer a free-form question against the computed summary.

If you're viewing this without the backend running, the status pill above will say so, and every number on the page instead comes from a small client-side heuristic (visible in frontend/app.js) rather than the trained model — useful for a zero-setup look, but the backend is what this project is actually evaluated on. Start it with cd backend && python train.py && uvicorn main:app --reload, then reload this page.
